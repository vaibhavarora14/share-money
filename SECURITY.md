# Security Policy

## Supported Versions

We actively support and release security patches for the latest version of SharedMoney.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

The SharedMoney maintainers take security seriously. If you discover a vulnerability or potential security risk in this repository, please do **NOT** open a public issue or discussion.

Instead, please report it via one of the following methods:

1. **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability" button under the **Security** tab of this repository.
2. **Direct Email**: Send encrypted or detailed disclosures to [contact@sharedmoney.app](mailto:contact@sharedmoney.app) with the subject `[SECURITY] Potential vulnerability in SharedMoney`.

### What to include in your report:

- A description of the issue and potential impact
- Affected component(s) (e.g. Supabase Edge Functions, Row Level Security policies, Expo mobile app, Web frontend)
- Step-by-step reproduction instructions or proof-of-concept code
- Any proposed mitigations or remediation steps

### Response Timeline

- **Initial Response**: Within 48 hours, an acknowledgement of receipt and assessment.
- **Triage & Status**: Updates provided as the vulnerability is verified and patched.
- **Public Disclosure**: Coordinated after a fix has been tested and deployed.

Thank you for helping keep SharedMoney and our users safe!
